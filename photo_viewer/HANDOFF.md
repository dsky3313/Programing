# 현장사진 뷰어 인계 노트 (2026-11-11)

## 목표
Acrobat Pro DC로 PDF(외관조사망도)를 볼 때, 옆에 폴더트리를 띄워 해당 담당자의 현장사진을 바로 확인. 썸네일은 불필요.

## 배경 / 결정 사항
- Acrobat Pro DC 자체에는 폴더트리 패널을 넣을 수 없음 (SDK 플러그인 개발이 필요해 과함). 무료 Reader는 서드파티 플러그인 미지원.
- 선택한 방식: Acrobat 옆에 붙이는 별도 프로그램 (Python + tkinter + Pillow). Win+← / Win+→ 로 나란히 배치.
- 폴더 구조 (캡처에서 확인)
  - PDF: `<프로젝트>/태블릿야장/02. 2026.06.26~27(야)/01. 김맹신이사/*.pdf`
  - 사진: `<프로젝트>/현장사진/04 2026.06.18(구룡지하차도)/01 김맹신이사/크기변환/*.jpg`
  - 프로젝트 폴더: `C:\Users\User\Desktop\김도호\2026\구룡\1015 구룡지하차도 하이퍼링크` (코드 기본값)
  - 사진은 `크기변환` 폴더(640x480)만 사용

## 동작
1. Acrobat이 전경 창일 때 창 제목에서 PDF 파일명을 읽음 (1초 폴링).
2. `태블릿야장`을 os.walk로 검색해 PDF 상위 폴더명에서 담당자 추출 (앞 번호 제거: `01. 김맹신이사` → `김맹신이사`).
3. `현장사진/<날짜>/<담당자>/크기변환` 사진을 모든 날짜에서 모아 날짜별 파일명 목록으로 표시 (`크기변환`이 없으면 담당자 폴더 직접). 파일명 더블클릭/Enter 시 별도 창에 원본 크기로 사진 표시 (창 하나 재사용).
4. 자동 인식 실패 시 상단 드롭다운에서 담당자 직접 선택.
- 기본 경로가 없으면 첫 실행 때 프로젝트 폴더를 선택, 선택하면 `photo_viewer.json`에 저장.

## 상태
- 코드: `photo_viewer.py` (같은 위치에 저장됨, 없으면 대화 첨부본 참고)
- 검증: 문법 검사 + 폴더 탐색/담당자 인식 로직만 테스트. **GUI는 Windows에서 미실행** (샌드박스에 tkinter/Windows 없음).

## 알려진 한계 / 가정
- 담당자 연결은 번호를 뗀 폴더명이 두 쪽에서 같을 때만 성립.
- 같은 파일명 PDF가 여러 폴더에 있으면 먼저 찾은 쪽 사용.
- 6/26~27 야간 작업 PDF인데 확인된 사진 폴더는 6/18자 — 해당 날짜 사진 폴더가 따로 있는지 확인 필요.
- JPG/JPEG/PNG만 표시.

## 다음 단계

## 2026-11-11 추가 반영
- exe 빌드: GitHub Actions(`.github/workflows/build-photo-viewer.yml`)가 Windows에서 `photo_viewer.exe`를 만들어 Artifact로 올림.
- Acrobat 창 오른쪽에 자동으로 붙음 (0.3초 확인). 오른쪽 자리가 없으면 Acrobat 폭을 줄임. 상단 "옆에 붙이기" 체크로 끄기 가능.
- 담당자 드롭다운 순서: 폴더명 앞 번호(01, 02, 03… 직함순).
- 프로젝트 폴더 자동 지정: 열려 있는 탐색기 폴더 → exe 위치의 상위 폴더 중 `태블릿야장`+`현장사진`이 있는 곳. 못 찾으면 저장값 → 기본 경로 → 선택 창. PDF 담당자를 못 찾으면 다시 탐색.
